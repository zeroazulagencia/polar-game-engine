Cómo se hace un juego

Tres pasos, todo en el navegador

Abres el editor en tu computador y lo que haces se guarda como archivos normales, listos para versionar con git.

01

Diseña las escenas

Pones el fondo, dibujas dónde se puede caminar y las zonas con las que se interactúa. El personaje se achica al alejarse y pasa por detrás de los objetos.

02

Escribe la historia

Diálogos con opciones, objetos que se recogen y se usan, variables, misiones, cinemáticas y varios finales.

03

Publica

Un clic y tienes una página web, una app de escritorio o una app de Android con tu juego adentro.

Diálogos

Conversaciones que dependen de lo que hizo el jugador

Cada línea puede mostrarse solo si se cumple algo, y cada opción puede dar objetos, cambiar de escena, mostrar una cinemática o terminar el juego.

  • Opciones de respuesta y ramas
  • Condiciones por variables y objetos del inventario
  • Versiones de cada diálogo para comparar y volver atrás

Verificador

Un jugador que prueba todas las partidas por ti

El verificador recorre las combinaciones posibles con las mismas reglas del juego y te dice si se puede llegar a cada final, y qué acciones dejan al jugador atascado para siempre.

  • Un camino de ejemplo hasta cada final
  • Objetos y variables que nunca se consiguen
  • Misiones que nadie puede completar

Empezar

Corre en tu computador en un minuto

Necesitas Node.js 20.9 o más nuevo.

$ git clone https://github.com/zeroazulagencia/polar-game-engine.git
$ cd polar-game-engine
$ npm install
$ npm run dev
# abre http://localhost:4600
  1. Se abre la demo: RIPMAN tiene que escapar de su celda. Entra a Jugar para probarla.
  2. Mira cómo está hecha en Editor de escenas, Diálogos y Título y cinemáticas.
  3. Crea tu juego desde el menú del proyecto → Nuevo proyecto.
  4. Cuando esté listo, Exportar juego.
